2. Was diese Anwendung ist

Die Gaming Content Engine ist ein privates Werkzeug, das ausschließlich vom Verantwortlichen selbst genutzt wird. Sie erstellt Kurzvideos aus eigenem bzw. lizenziertem Material und veröffentlicht sie auf den eigenen Kanälen des Verantwortlichen. Sie wird keinen anderen Personen angeboten; es gibt keine Registrierung und keine Konten für Dritte.

3. Welche Daten verarbeitet werden

  • Daten der eigenen Plattform-Konten über die offiziellen Schnittstellen: Kanal- bzw. Kontokennung und -name, eigene Videos und Beiträge, deren Status sowie Kennzahlen (z. B. Aufrufe, Wiedergabezeit, Interaktionen).
  • Zugangs-Token der Plattformen, die beim Verbinden eines Kontos ausgestellt werden. Sie werden verschlüsselt gespeichert und nur für die genannten Zwecke verwendet.
  • Öffentliche Trenddaten (z. B. beliebte Videos und Spiele), ohne Bezug zu einzelnen Personen.

Es werden keine Daten anderer Nutzerinnen und Nutzer gesammelt, keine Profile gebildet, keine Daten verkauft und keine Daten an Dritte weitergegeben, außer an die unten genannten technischen Dienstleister.

4. YouTube API Services

Diese Anwendung nutzt die YouTube API Services. Es gelten die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google. Der Zugriff auf das Google-Konto kann jederzeit unter security.google.com/settings/security/permissions widerrufen werden.
